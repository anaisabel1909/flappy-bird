🐦 Flappy Bird Clone

Um clone do clássico Flappy Bird, desenvolvido com HTML, CSS e JavaScript, com foco em praticar lógica de programação, manipulação do DOM e animações no navegador.

🚀 Funcionalidades
Movimento do personagem com interação do usuário
Sistema de colisão
Contador de pontos
Obstáculos gerados dinamicamente
Game over ao colidir

🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript (Vanilla JS)

🎮 Como jogar
Abra o arquivo index.html no navegador
Pressione uma tecla (espaço, seta para cima ou x) para fazer o pássaro subir
Desvie dos obstáculos
Tente fazer a maior pontuação possível!

📌 Objetivo do projeto
Este projeto foi criado com o objetivo de praticar conceitos fundamentais de desenvolvimento web, como:
Manipulação do DOM
Eventos em JavaScript
Lógica de jogos
Animações com CSS/JS
